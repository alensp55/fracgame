# fracgame

`fracgame` — независимое воссоздание с нуля DOS-головоломки FRAC 1990 года на Godot.
Объёмные фигуры падают в стакан размером 5×5×12. Заполненные горизонтальные слои исчезают,
а всё, что находится выше, опускается вниз.

Репозиторий содержит только новую реализацию. Оригинальный DOS-файл игры, графика и другие игровые файлы
в него не включены.

## Возможности

- Девять исходных типов объёмных фигур и восстановленные веса их выбора.
- Перемещение с клавиатуры и цифрового блока, в том числе по диагонали.
- Циклическое вращение одной кнопкой.
- Проекции активной фигуры на обеих дальних стенках без тени на дне.
- Восстановленные скорости падения, время смены уровней, таблица бонусов и правила подсчёта очков DOS-версии.
- Настройка размеров стакана, начального уровня, заполненных слоёв на старте и доступных фигур.
- Локальная таблица десяти лучших результатов.

## Управление

- Стрелки или `QWE` / `AD` / `ZXC`: перемещение фигуры.
- Цифровой блок `1`–`9`: перемещение в восьми направлениях; `5` — вращение.
- `S`: вращение.
- `Space`, `Insert`, `Delete`, `0` или десятичная точка на цифровом блоке: мгновенное падение.
- `Enter`: увеличение уровня скорости.
- `P` или `Escape`: пауза.

## Запуск из исходников

Откройте `project.godot` в Godot 4.7 или новее.

Запуск автоматических тестов:

```powershell
& "C:\path\to\Godot_console.exe" --headless --path . --script res://tests/run_tests.gd
```

Текущий скрипт сборки для Windows ожидает Godot 4.7.2 в `C:\path\Godot`:

```powershell
.\build_windows.ps1
```
